Publii 手动同步Git仓库

假设设置的分支名是gh-pages：

Publii本地分支只有一个提交，把本地提交的内容打包成一个新提交直接放在远端之上：

git fetch origin gh-pages
# HEAD 移到远端最新提交，但保留本地文件改动
git reset --soft origin/gh-pages 
# 用原来本地提交的 message 重新提交
git commit -C "HEAD@{1}"
git push origin gh-pages
